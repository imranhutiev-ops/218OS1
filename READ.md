# 218OS
# Битоническая сортировка (Параллельная и последовательная)
Лабораторная работа по параллельному программированию (WinAPI / C)

## Описание файлов
* `bitonic.h` / `bitonic_serial.c` / `bitonic_parallel.c` — реализация битонической сортировки
* `io.h` / `io.c` — вспомогательные функции тайминга и ввода
* `main.c` — генерация данных, запуск тестов, проверка корректности и расчет ускорения

## Для запуска нужно:
gcc main.c bitonic_serial.c bitonic_parallel.c io.c -o program.exe
## а после 
.\program.exe potoc n pause

potoc — количество потоков  > 0

n — количество элементов для сортировки (автоматически округляется вверх до ближайшей степени 2).
pause — (необязательно) передайте любой аргумент, чтобы приостановить потоки перед стартом для проверки их количества в диспетчере задач.
